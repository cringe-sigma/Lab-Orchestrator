### 2.3 精细权限管控 — 核心能力

```
点击用户行的 [🔐 权限] → 弹出权限管理面板

┌──────────── 用户 user1 (小明) 的权限 ────────────┐
│                                                   │
│ 权限键          说明              状态  来源   操作 │
│ ─────          ────              ──   ────   ─── │
│ boards:read    查看板子           ✅  角色   [收回]│
│ boards:create  添加板子           ❌   —     [授予]│ ← 点击授予
│ boards:exec    操作板子           ✅  角色   [收回]│
│ boards:delete  删除板子           ❌   —     [授予]│
│ experiments:read 查看实验          ✅  角色   [收回]│
│ experiments:create 创建实验        ✅  角色   [收回]│
│ experiments:run 运行实验           ✅  角色   [收回]│
│ bookings:read  查看预约           ✅  角色   [收回]│
│ bookings:create 创建预约           ✅  角色   [收回]│
│ bookings:cancel 取消预约           ✅  角色   [收回]│
│ users:read     查看用户           ❌   —     [授予]│
│ users:manage   管理用户           ❌   —     [授予]│
│ permissions:approve 审批权限       ❌   —     [授予]│
│ ai:chat        使用AI助手         ✅  角色   [收回]│
│                                                   │
│ 当前有效权限: 9/14 项                              │
└───────────────────────────────────────────────────┘

三种操作:
  [授予]  → 添加 grant 覆写 → 用户立即拥有此权限
  [收回]  → 添加 revoke 覆写 → 用户立即失去此权限
  [恢复默认] → 删除覆写 → 回到角色默认权限

权限生效规则:
  用户有效权限 = (角色默认) + (你授予的) - (你收回的)
```

## 3. 🔧 维护者操作手册

> 维护者负责板子的物理连接和系统运维。角色: user 或 admin

### 3.1 板子接入 — 三种方式

```
板子管理 → 🔌接线教程 → 选择板子类型 → 5步向导
```

#### 方式1: SSH 本地板子 (树莓派等 Linux 板)

```
物理连接:
  服务器 ←网线→ 交换机 ←网线→ 板子RJ45口
  板子 ←USB-C→ 电源适配器

操作步骤:
  Step 1: 网线插好，板子通电
  Step 2: 板子上 sudo systemctl enable ssh --now
  Step 3: 板子上 ip addr → 记录IP (如 192.168.1.101)
  Step 4: 电脑上 ping 192.168.1.101 验证
  Step 5: 前端添加板子 → SSH → 填写IP/端口/用户名
  Step 6: 点击"检查" → 状态变"在线" ✅
```

#### 方式2: 串口本地板子 (STM32/ESP32 等 MCU)

```
物理连接:
  电脑USB口 ←→ USB转串口(CH340G) ←→ 板子
                        GND ──── GND
                        TXD ──── RXD  (交叉!)
                        RXD ──── TXD  (交叉!)

操作步骤:
  Step 1: 插上USB转串口模块
  Step 2: Windows: 设备管理器查看COM号
          Linux: ls /dev/ttyUSB*
  Step 3: 杜邦线按 TXD→RXD, RXD→TXD, GND→GND 接好
  Step 4: 板子通电
  Step 5: 前端添加 → 串口 → 填写串口号/波特率
  Step 6: 关闭其他串口工具(PuTTY等) → 点击"检查"
```

#### 方式3: 远程板子 (任意网络位置的板子)

```
原理:
  板子主动向服务器发起WebSocket连接
  不需要公网IP，不需要端口映射

操作步骤:
  Step 1: 前端添加板子 → 远程代理 → 系统生成Token
  Step 2: 将Token发给板子所在位置的操作人员
  Step 3: 在板子上:
          pip install websockets
          python agent.py --server ws://服务器IP:8000/ws/board --token TOKEN
  Step 4: 板子自动注册上线
  Step 5: 设置自启: systemctl enable lab-agent
  Step 6: 前端确认状态为"在线"
```

## 4. 👤 用户操作手册

> 普通用户 (role=user)。你是板子的使用者。

### 4.1 登录和概览

```
http://服务器IP:5173 → 登录

总览页显示:
  · 可用板子总数
  · 当前在线数
  · 你的实验记录
  · 你的预约记录
```

### 4.2 查看可用板子

```
板子管理 → 查看所有已接入的板子

你可以:
  ✅ 查看所有板子列表和状态
  ✅ 检查板子是否在线
  ✅ 执行命令 (需要板子未被占用)
  ❌ 不能添加/删除板子 (除非管理员授予 boards:create)
```

### 4.3 预约板子 — 完整流程

```
Step 1: 导航 → 预约 → +新建预约

Step 2: 填写预约单
  · 选择板子 (下拉列表显示所有在线板子)
  · 填写标题 (如: "GPIO接口测试实验")
  · 设置时间段 (开始~结束，最长4小时)

Step 3: 确认 → 系统检测时间冲突
  · 无冲突 → 创建成功 (状态: 待开始)
  · 有冲突 → 提示"该时段已被预约" → 换时间

Step 4: 时间到达 → 预约自动激活 (状态: 进行中)
  · 现在你可以操作这块板子了
  · 你独占使用，其他人无法操作

Step 5: 操作板子
  方式A: 板子管理页 → 找到板子 → 执行命令
  方式B: AI助手 → 自然语言操作
  方式C: 实验页 → 创建正式实验记录

Step 6: 时间到达 → 预约自动结束 → 板子释放

可随时取消未开始的预约:
  预约列表 → 找到该预约 → [取消]
```

### 4.4 执行实验

```
方式1: 板子管理页直接执行 (快速测试)

  板子卡片 → [执行命令]
  输入: ls /home/pi
  输入: python test.py
  输入: gcc main.c -o test && ./test

方式2: 实验页 (正式记录)

  实验 → +新建实验
  · 选择板子
  · 填写实验名称
  · 创建 → [运行]
  · 执行结果保存到实验记录
  · 可回看历史实验详情

方式3: AI 助手 (最便捷)

  AI助手 → 选择板子 → 直接描述需求:
  "帮我跑GPIO引脚18的输出测试"
  "编译test.c并运行，看有没有报错"
  "检查CPU温度和内存使用率"
  "创建一个循环测试，跑100次并统计通过率"

  AI 会:
    1. 生成实验步骤 → 展示给你确认
    2. 确认后逐步执行
    3. 每步返回结果
    4. 完成后生成总结
```

## 5. 三角色交叉场景

### 场景: 新同事入职

```
1. 👑 管理员:
   · 登录 → 用户管理 → 通知新同事注册
   · 或直接给他创建账号
   · 分配初始角色 (通常是 user)
   · 如需要: [🔐权限] → 额外授予特定权限

2. 👤 新同事 (用户):
   · 登录 → 查看板子
   · 去权限页了解自己能做什么
   · 去手册页学习操作方法
   · 如需额外权限 → 提交申请

3. 👑 管理员:
   · 审批权限申请 → 通过/拒绝 + 意见
```

### 场景: 新板子接入

```
1. 🔧 维护者:
   · 物理接线 (网线/串口/USB供电)
   · 板子端配置 (SSH/固定IP)
   · 验证连通 (ping/SSH测试)

2. 👑 管理员 (或维护者):
   · 登录 → 板子管理 → 添加板子
   · 选择连接方式 → 填写连接信息
   · 点击检查 → 确认上线

3. 👤 用户:
   · 看到新板子出现在列表中
   · 可以预约和使用
```

### 场景: 权限申请与审批

```
1. 👤 用户:
   · 权限页 → 发现没有 "boards:create"
   · 申请权限 → 理由: "需要添加自己的板子做实验"
   · 提交申请

2. 👑 管理员:
   · 管理后台 → 待审批 Tab → 看到申请
   · 评估: 合理需求 → [✅ 通过]
   · 或: 不合理 → [❌ 拒绝] + 填写理由

3. 👤 用户:
   · 权限页 → 申请记录 → 看到"已通过"
   · 我的权限 → boards:create 变为 ✅ 来源:额外授予
   · 现在可以去添加板子了
```
